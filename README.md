# Dynamic Lights for Horizon

A native Rust mixin port of **LambDynamicLights** for [Horizon](https://github.com/horizon-rust/horizon) (Minecraft: Java Edition 26.3), created by **CayMac**.

## Features (1:1 LambDynamicLights Parity)

- **Handheld Dynamic Lighting:** Holding torches, lanterns, glowstone, sea lanterns, shroomlights, lava buckets, blaze rods, glow ink sacs, or nether stars in either your **main hand** or **offhand** illuminates the world around you smoothly.
- **Water-Sensitive Extinguishing:** Open-flame light sources (`torch`, `soul_torch`, `redstone_torch`, `campfire`, `soul_campfire`, `candle`, `lava_bucket`) automatically extinguish when submerged underwater, while waterproof sources (`lantern`, `soul_lantern`, `sea_lantern`, `glowstone`, `shroomlight`, `froglight`, `jack_o_lantern`, `sea_pickle`, `conduit`, `end_rod`) stay lit underwater.
- **Glowing & Burning Entities:** Blazes, Glow Squids, Magma Cubes, Allays, Vexes, charging Creepers, and any entity on fire emit real-time dynamic block light.
- **Dropped Item Lighting:** Torches and glowing items dropped on the ground illuminate caves and shafts as they fall.
- **Instant Toggle Keybind (`L`):** Toggle Dynamic Lights on or off anytime during gameplay.
